# scripts/canonical_remote.py), not as the URLs themselves. Writing the private repository's URL in plain text here would

# — the same shape of mistake as a deny-list that leaks its own entries.
# Cross-review (agy, P1, 2026-08-15) caught the plaintext version.

# The digest still does the job: hooks/pre-push hashes the remote URL git hands
# it and compares. It cannot be reversed into the URL by a reader.
#
# This file must exist and must be non-empty. Absence, an unreadable file, or
# no usable entries are all treated as undecidable and reject the push.
#
# Add an entry with:
#   python3 scripts/canonical_remote.py --digest <url>
#
# Canonicalizing first is what makes the entry cover every spelling of the same
# destination — ssh and https, with or without .git, any host case.
