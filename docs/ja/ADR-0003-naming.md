# ADR-0003: 命名規約

- Status: Accepted（2026-07-18）

## Decision

| 名前 | 意味 |
|---|---|
| **incierge** | 器。層を束ねる monorepo の名前であり、個々の機能の名前ではない |
| **xxx-ops** | 層名の規約。`agent-ops`＝個人層、`org-ops`＝組織層 |
| **unk0** | 正準状態層。「今の正本は何か」に答える canon/state エンジン |
| **metrology** | 計測層。コーパス衛生・トークナイザ・極小 LM の計測/学習スタック |

## 規則

1. 新しい層を足す場合、運用系は `xxx-ops` 形式、非運用系（状態・計測など）は
   役割を表す単語 1 語を用いる。
2. 層ディレクトリ名＝層名。repo 名や旧名（opskit / lm-stack 等）は履歴とドキュメント
   にのみ残り、器の中の構造には現れない。
3. 旧名との対応は README の層一覧表を正とする。
